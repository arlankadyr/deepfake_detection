02 / THE PROJECT

What are we looking for?

Can detectors trained on GAN-generated images recognise images made by diffusion models?

This demonstration compares a convolutional neural network with a Vision Transformer. Both are fine-tuned to distinguish real images from BigGAN-generated images in the GenImage dataset, then intended to be evaluated on diffusion-generated images.

A

ResNet-50

A convolutional network that builds visual features through layers of residual connections.

B

DeiT-S

A data-efficient Vision Transformer that learns relationships between image patches.
